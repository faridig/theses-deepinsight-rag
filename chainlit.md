# 🎓 DeepInsight Theses RAG

Bienvenue dans l'interface conversationnelle de recherche de thèses. Ce système utilise une architecture RAG (Retrieval-Augmented Generation) avancée pour vous aider à explorer le corpus national des thèses.

## 🚀 Fonctionnalités
- **Recherche Sémantique** : Posez des questions en langage naturel sur n'importe quel sujet de recherche.
- **Transparence** : Visualisez le raisonnement du système (Chain of Thought) et les sources citées.
- **Accès direct aux sources** : Cliquez sur une source pour visualiser le PDF original dans le panneau latéral.
- **Évaluation en temps réel** : Consultez les scores de fiabilité (Faithfulness, Relevancy) pour chaque réponse.

## 📊 Dashboard de Qualité
Utilisez le panneau latéral pour accéder au dernier rapport d'audit et aux traces d'exécution dans **Arize Phoenix**.

## 💡 Exemple de questions
- *"Quels sont les impacts de l'intelligence artificielle sur le système scientifique ?"*
- *"Quelles thèses traitent de la détection de fake news via le deep learning ?"*
- *"Explique-moi les concepts clés de la thèse de Jean Dupont sur les graphes de connaissances."*
